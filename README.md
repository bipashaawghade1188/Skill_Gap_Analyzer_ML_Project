# AI Skill-Gap Analyzer & Career Path Predictor

An AI-powered Machine Learning and NLP project that analyzes a candidate's resume, extracts technical skills, predicts suitable career roles, identifies missing skills, and provides personalized career and learning recommendations.

## 🚀 Features

- 📄 Resume PDF text extraction
- 🔍 Automatic skill extraction using NLP
- 🤖 Career role prediction
- 📊 Career match percentage
- ❌ Skill-gap identification
- 🎯 Target career recommendation
- 📚 Personalized learning recommendations
- 🛣️ Career path prediction
- 📈 Interactive analysis dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- NLP
- TF-IDF
- Cosine Similarity
- PyMuPDF
- SQL
- Jupyter Notebook
- Git & GitHub

## 🔄 Project Workflow

Resume Upload
→ Text Extraction
→ NLP Preprocessing
→ Skill Extraction
→ Career Prediction
→ Skill-Gap Analysis
→ Learning Recommendation
→ Career Path Prediction

## 🎯 Example

A candidate uploads a resume containing:

Python, SQL, Pandas, NumPy, Power BI, and Machine Learning.

The system analyzes these skills and may recommend:

Data Analyst — 88%
Data Scientist — 76%
ML Engineer — 52%

It then identifies missing skills for the recommended career and suggests what the candidate should learn next.
